<p>XComb turns your Android phone into a real ARM64 Linux workspace. It unpacks Alpine Linux inside the app and opens a terminal where <b>Claude Code</b>, <b>Codex</b>, <b>OpenCode</b>, <b>Gemini CLI</b> and <b>FreeBuff</b> can read your code, edit files, run tests and tell you what broke. No root, no Termux, and no computer required.</p>

<p>Ask an agent to fix a failing test while you're on the bus, then put the phone away. Sessions run in a foreground service, so they keep working with the screen off, and XComb sends a notification when an agent finishes or needs an answer.</p>

<p><b>What you get</b></p>
<ul>
<li><b>Coding agents in one tap.</b> Pick Claude Code, Codex, OpenCode, Gemini CLI, FreeBuff or a bare zsh terminal. XComb installs each agent the first time you open it, with the installer output right there in the terminal. You sign in inside each CLI; XComb never sees your provider credentials.</li>
<li><b>A real Linux shell.</b> Alpine comes from a pinned minirootfs whose SHA-256 digest is checked before anything is unpacked, and git, curl, ripgrep, Python and Node are installed on demand. npm test, pytest and a static ffmpeg build all run the way they would on a server.</li>
<li><b>A terminal you can use with your thumbs.</b> Swipe typing works, links open with a tap, and a key bar above the keyboard adds Esc, Tab, arrows, paste, and one-shot Ctrl and Alt.</li>
<li><b>Your projects.</b> Create a folder, clone any HTTPS or SSH Git URL, or sign in to GitHub and pick one of your repositories.</li>
<li><b>Up to four sessions at once</b>, each with its own notification.</li>
<li><b>A full file manager.</b> Browse phone storage, your Linux home, the shared workspace and Favorites. Search, sort, multi-select, copy, cut, paste, rename, delete, share, compress to zip, unzip, or import files from the phone picker. Config folders open in the same manager, locked to that tool's directory.</li>
<li><b>Phone storage for your agents.</b> Grant All files access and XComb binds /sdcard into Linux, so Claude Code, Codex, OpenCode, Gemini CLI and FreeBuff can read and write the files you choose.</li>
<li><b>A lock.</b> An optional password protects the app, and the workspace locks itself after 15 minutes in the background.</li>
<li><b>Optional USB access from a computer.</b> Pair a computer over USB to get an SSH shell on the phone. It is off by default, listens only on the phone's loopback (reached through adb), and accepts only paired keys.</li>
<li><b>A focused yellow interface.</b> A warm black workspace, bright yellow accent, official agent marks, and the XComb icon and avatar set.</li>
</ul>

<p><b>Things to know</b></p>
<ul>
<li>XComb needs an ARM64 (arm64-v8a) phone running Android 7.0 or newer.</li>
<li>Alpine, its packages and the agents download from their servers when you first use them; mirrors are available in Settings. Claude Code and Codex need accounts with their providers. Claude Code is proprietary, while Codex (Apache-2.0), OpenCode, Gemini CLI, FreeBuff and the shell have their own licenses.</li>
<li>Android's app sandbox is the only security boundary. PRoot emulates user IDs but gives no kernel isolation, so don't run code you don't trust.</li>
<li>This build uses the new application ID com.scariflabs.xcomb, so it is a fresh install. The older app stays separate and its data is not migrated. Uninstall an older build before installing XComb, because each CI build uses a fresh signing key.</li>
<li>All files access is optional. Android/data and Android/obb remain restricted even after it is granted. Archive support is zip only; 7z and custom compression are not included.</li>
</ul>
